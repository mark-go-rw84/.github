## Getting Started Playbook
Launch Mark Go, load a photo, and set the brush to roughly the width of the watermark. Paint across the mark so the whole overlay is covered by your stroke.

Tap the go control and the region fills with matching background. Zoom in to check the seam, undo and repaint if a spot lingers, then export the finished picture straight to your gallery.
